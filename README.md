# Frentes de TI no Programa 60 Anos — Fenasbac

Painel das quatro frentes de Tecnologia dentro do Programa 60 Anos
("Há 60 anos nosso legado é o futuro"), de janeiro a novembro de 2026.
Coordenação de TI · insumo para o relatório do Programa ao Conselho.

## Painel

Publicado via GitHub Pages:

**https://lenita-costa.github.io/frentes-ti-60-anos/**

O painel é um arquivo único, sem dependências externas: abre no navegador e
permite exportar em PDF (pela impressão) ou os dados em CSV.

## O que o painel cobre

| Seção | Conteúdo |
|---|---|
| Adesão das regionais ao Conecta | Base integrada, termo de adesão e ponto focal |
| As quatro frentes de TI | Integração de dados (Cérebro), Conecta (Esqueleto), Clube F e Site (Sentidos) |
| Planejado em janeiro x hoje | O que o plano previa para cada entrega e onde estamos |
| Situação por regional | Modelo, termo, ponto focal e casos de análise manual (jul–out) |
| Clube F: análise manual | Resultado dos casos e como funciona a validação em três níveis |
| Site e área logada | Entregas do site, da área logada e da página dos 60 anos |
| Brasília: de planilhas para a API | Integração com a WBC, fornecedora do sistema da ASBAC Brasília |
| Marcos por mês e por frente | Linha do tempo cruzando mês e frente |
| Atenção e próximos passos | Obstáculos, encaminhamento, próximo passo e responsável |

Os números de funil e uso do Clube F estão no report mensal do Marketing;
este painel cobre apenas a parte de TI.

## Estrutura

```
index.html   painel completo (publicado no Pages)
.nojekyll    desliga o processamento Jekyll do GitHub Pages
```

## Como atualizar

Substituir o `index.html` pela versão nova do painel, commitar e dar push na
`main`. O Pages reconstrói sozinho em cerca de 30 segundos.
