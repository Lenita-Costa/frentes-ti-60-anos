Três formas de usar o Conecta

O Conecta reúne as bases de associados das regionais; cada regional vê e edita só a sua, e a Federação mantém a visão consolidada. O modelo depende de a regional já ter ou não um sistema próprio.

Brasília: de planilhas para a API

Brasília é a regional com mais casos de análise manual e a única que integra por API, com a WBC, fornecedora do sistema da ASBAC Brasília. API é a ligação direta entre dois sistemas, sem planilhas.
